1. Ce face proiectul?

Proiectul implementeaza o agenda digitala de activitati — un sistem care permite organizarea sarcinilor pe domenii (categorii), gruparea lor in proiecte si gestionarea lor printr-o agenda centrala.

Analogie: Gandeste-te la un planner fizic. Ai categorii colorate (Domenii), sarcini individuale (Activitati) si dosare tematice (Proiecte). Agenda este plannerul in sine.

ElementAgenda abstract class

Clasa de baza pentru Domeniu, Activitate si Proiect. Contine tot ce au in comun aceste entitati. Nu poate fi instantiata direct.

Mecanism important — ID unic automat:
private static int contorID = 0;
La fiecare creare de obiect (inclusiv copii): this.id = ++contorID
Contorul este static → e partajat de toate instantele, ID-urile sunt mereu unice si crescatoare. 
public abstract class ElementAgenda : IExportabil
{
    private static int contorID = 0;  // partajat de toate instantele

    public int      Id        { get; }          // auto-generat
    public string   Titlu     { get; set; }
    public string   Descriere { get; set; }
    public DateTime DataCreare { get; set; }

    public abstract string sumar();          // TREBUIE implementat de subclase
    public virtual string  ExportText() ...  // POATE fi suprascris
    public virtual string  ExportXML()  ...
}
Domeniu class

Reprezinta o categorie (ex: Facultate, Munca, Personal). Cel mai simplu element din ierarhie.

Proprietati

  • Culoare — culoarea categoriei (default "Gri")
  • Titlu, Descriere, DataCreare — mostenite

Interfete implementate

  • ICloneable — Clone() via MemberwiseClone()
  • IComparable — alfabetic dupa Titlu, la egalitate dupa DataCreare

Operatori supraincarcati

  • < / > — ordine alfabetica (via CompareTo)
  • == / != — egalitate dupa Titlu, nu dupa referinta
facultate == copie → true

Activitate class

Elementul central al aplicatiei. O sarcina concreta, cu interval de timp si prioritate.

StatusActivitate — enum

public enum StatusActivitate
{
    Noua,        // stare initiala la creare
    InProgres,   // dupa IncepeActivitatea()
    Finalizata,  // dupa MarcheazaFinalizata()
    Anulata
}

Campuri proprii

  • Domeniu — referinta la un obiect Domeniu (asociere)
  • DataStart / DataEnd — intervalul activitatii
  • Prioritate — 1 (minima) la 5 (maxima), auto-clampata
  • Status — din enum-ul de mai sus
  • Locatie — optional, default ""

Operatori supraincarcati

  • a1 > a2 — a1 are prioritate mai mare
  • a1 < a2 — a1 are prioritate mai mica
  • a++ — creste prioritatea cu 1 (max 5)
  • a-- — scade prioritatea cu 1 (min 1)
  • (string)a — cast explicit → returneaza sumar()

IComparable — logica de sortare

// Compara intai dupa DataStart (crescator),
// la egalitate: prioritate mai mare vine PRIMA (descrescator)
public int CompareTo(object obj)
{
    Activitate a = (Activitate)obj;
    int cmp = this.dataStart.CompareTo(a.DataStart);
    if (cmp != 0) return cmp;
    return a.Prioritate.CompareTo(this.prioritate); // inversat!
}

AgendaActivitati class

Containerul principal al aplicatiei. Gestioneaza toate cele trei colectii si implementeaza pattern-ul Delegate + Event pentru notificari.

Pattern Delegate + Event — pas cu pas

// Pas 1: clasa de argumente personalizate
public class AgendaEventArgs : EventArgs
{
    public string Actiune     { get; set; }  // "ADAUGARE", "STERGERE", "SALVARE"
    public string NumeElement { get; set; }  // ex: "Proiect C#"
}

// Pas 2: delegatul (semnatura metodei-handler)
public delegate void AgendaEventHandler(object sender, AgendaEventArgs e);

// Pas 3: eventul (in clasa AgendaActivitati)
public event AgendaEventHandler NotificareModificare;

// Pas 4: metoda care declanseaza notificarea
private void DeclanseazaNotificare(string actiune, string numeElement)
{
    if (NotificareModificare != null)
        NotificareModificare(this, new AgendaEventArgs(actiune, numeElement));
}

// In Program.cs — abonare la event:
agenda.NotificareModificare += new AgendaEventHandler(CandSeModificaAgenda);

// Handler-ul (metoda care se executa la notificare):
static void CandSeModificaAgenda(object sender, AgendaEventArgs e)
{
    Console.WriteLine($"  >> NOTIFICARE [{e.Actiune}]: {e.NumeElement}");
}
